 🎬 Movie Recommendation System

This is a simple movie recommendation web app built using Python and Streamlit.  
It suggests movies similar to the one you select and shows their posters and basic details.



🚀 Live Demo
[](https://mrsbysiraj0503.streamlit.app/)


💡 What this project does

- You select a movie from a dropdown
- It finds similar movies based on similarity scores
- Shows top 5 recommended movies
- Displays posters and some details like rating and overview



 🧠 How it works (simple explanation)

The project is based on content similarity between movies.

- Movies are converted into feature vectors
- Similarity is calculated between them
- Based on the selected movie, closest matches are shown



🛠️ Tech used

- Python
- Streamlit
- Pandas
- Requests
- TMDB API
